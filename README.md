MSRDC Admin Dashboard

A modern and responsive MSRDC Admin Dashboard UI built using HTML, CSS, JavaScript, Bootstrap 5, and Chart.js.
This project includes dashboard analytics, transaction management, master tables, LSDU live status monitoring, dark mode, responsive design, and professional admin panel components.

🚀 Features

✅ Responsive Admin Dashboard
✅ Sidebar Navigation
✅ Modern Top Navbar
✅ Dashboard Cards
✅ Revenue Analytics Chart
✅ Transaction Review Page

✅ LSDU Live Status Monitoring

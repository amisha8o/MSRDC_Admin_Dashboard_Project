# 🚀 MSRDC Admin Dashboard System

A fully responsive and modern **MSRDC Admin Dashboard Web Application UI** developed using **HTML, CSS, JavaScript, Bootstrap 5, Font Awesome, and Chart.js**.

This project is designed to provide a professional admin panel experience with modern UI components, responsive layouts, transaction management systems, live status monitoring, dashboard analytics, and dark mode support.

The dashboard interface is inspired by real-world enterprise admin systems and focuses on clean design, usability, responsiveness, and user experience.
